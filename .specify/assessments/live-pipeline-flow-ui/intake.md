- **Source**: pasted text

## Idea (as captured)

> I want to run through the entire workflow of the voiceFaithfulness app. At the moment, I can only hear the sample text. The remaining data is stub data. I want to:
> - View a transcript of the conversation taken by an agent
> - View a summary produced by that agent of what that transcript looks like
> - be able to switch agents to see if there is a difference in quality of each agent's transcript and summary
> - Have the stronger agent attempt to judge the summary
> - View the different summaries generated by different agents
> - See a score of that instance and why the score was stated as it was
> - View the overall score of all judgements against all summaries
> - Improve the UI so all information can be shown in a flow (left to right)

## Restated

The owner wants the app’s full learning pipeline usable with real (non-stub) agent outputs: transcript and summary per selectable agent, comparison across agents, a stronger judge that scores a summary with an explanation, per-instance and aggregate scores, and a left-to-right UI that presents that flow end to end.

## Origin & Context

- **Raised by**: owner (session)
- **Trigger**: After using the local demo, only sample audio is audible; pipeline results still feel like stub data, so the full workflow is not yet learnable as intended.
