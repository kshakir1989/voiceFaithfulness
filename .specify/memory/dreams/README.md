# Dreams

Proposed (and usually auto-applied) memory consolidations from
`/speckit.dream.propose`.

Each run is a folder:

- `proposal.md` — candidates (kept as audit trail)
- `sources.md` — transcripts considered
- `apply.md` — what was auto-applied (or manual override)

`constitution.md` is never auto-edited. Soft patterns land in
`../learnings.md` automatically for medium+ learnings-bound candidates.
